Common questions

Is setup done for me?

In early access, we set up each automation with you. We will always tell you before you subscribe if any step needs our help.

What if a connection breaks?

The workspace shows it as Needs attention, with the issue and what to do next. Work that depends on it pauses rather than guessing.

What if nothing ran this week?

The workspace says so. A quiet week is shown as a quiet week, not hidden.

Can I change the rules later?

Yes. Most teams start with everything waiting for review, then let simple, trusted actions run on their own.
